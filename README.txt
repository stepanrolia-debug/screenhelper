1. Залейте все файлы этой папки в новый репозиторий GitHub (включая папку .github).
2. Вкладка Actions -> Build APK -> дождитесь зелёной галочки (3-5 минут).
3. Откройте завершённый запуск, внизу в Artifacts скачайте ScreenHelper-apk, распакуйте zip.
4. Перенесите app-debug.apk на телефон и установите.
